03 / FIRST DEPLOYMENT

三：进服基础教程

  1. 完成基本加点，解锁印痕。
  2. 按 F6 打开后，右下角点击进入商城，上方选择【礼包】，领取新手【抽奖礼盒】。
  3. 按 F2，点击【专属核心】，进入后找到【近战机甲】【远程机甲】，消耗一块石头点击激活；右侧栏选择后点击召唤，后续即可长按 F进行快捷召唤。
04 / RESOURCE & CHALLENGE

四：资源获取 · 地图挑战 · 副本挑战

⛏ 挖矿玩法

地图内刷新各种矿场，一阶至五阶资源都有，使用【挖矿机甲】采集。这是最安全稳妥的资源获取方式，也是资源获取效率最低的方式。

◈ 货币获取

在背包印痕内制作货币台，放入金属锭即可制作货币。货币用于制作高达、回收商城兑换特殊物品、拍卖等途径。

⚔ 地图 BOSS

全图随机刷新巨量低阶 BOSS，有手就能打！包含定点刷新点位。击杀获取一阶高达制作材料与副本券。

✦ 副本挑战

副本分为四种难度：二阶至五阶。挑战副本获取高阶高达制作材料与【升级卡】，提升高达等级属性！

一阶高达可挑战二阶副本，二阶可挑战三阶，以此类推。主要玩法就是制作更多帅气高达、升级提升！

05 / SPECIAL OPERATIONS

五：特殊玩法 · 注意事项

01 / 剧情玩法

每个玩家 F6 礼包内都会有三个信物【一阶神源】，用于开启剧情玩法。实力达到特定要求后，前往服主家 NPC 接取任务。

总共八个任务，极其困难。完成可获取丰厚报酬与最强高达【远古自由高达宇宙神之创世者】，成为专属！

02 / 世界 BOSS

每天【中午 12:00】与【晚上 20:00】都会刷新出强大 BOSS，击杀可获取大量奖励。

世界 BOSS 物品不会直接进入玩家背包，而是【掉落地上，需下专属拾取】。

03 / 属性注意事项

除了副本简介注意事项，还有属性问题：低温仓内的龙放出来后，切！记！【洗点】，避免爆点、丢失属性、意外阵亡！

06 / GUNDAM ARCHIVE

六：高达介绍 · 分阶图鉴

阶级是天堑！高阶防御和攻击力都比低阶龙高，低阶很难破高阶防御，等级很难弥补差距。同阶亦有差距，以下按你提供的顺序由高到低展示。

分级色彩：终极彩色 / 五阶红 / 四阶紫 / 三阶蓝 / 二阶黄 / 一阶绿；初阶采用冰蓝银色。

没有找到匹配的高达，试试其他名称或阶级。
